    Phishing Detection & Threat Heuristics Guide

    Phishing awareness training requires understanding how adversaries manipulate psychology and technical protocols. Below is a breakdown of the core heuristic techniques applied by this engine:

    1. Display Name Spoofing

    Adversaries set the friendly "Display Name" to a trusted brand (e.g., "PayPal Service") while the actual sending domain is unrelated (e.g., attacker@random-vps.com). Because mobile email clients emphasize display names over addresses, victims are easily misled.

    2. Reply-To Mismatches

    Phishers may forge legitimate organizations in the From: line, but set a hidden Reply-To: header pointing to their disposable mailbox so any response is routed directly to the attacker.

    3. SPF & DKIM Verification

    SPF (Sender Policy Framework) authorizes IP addresses allowed to send mail on behalf of a domain. DKIM (DomainKeys Identified Mail) provides a cryptographic digital signature ensuring message integrity. Failures or absences indicate potential forgery.

    4. Psychological Urgency & Scarcity

    Social engineering relies on urgency cues (e.g., "Within 24 hours", "Account suspended", "Immediate action required") to evoke anxiety and bypass rational analytical scrutiny.

    5. Typosquatting & Leetspeak

    Attackers register visual lookalike domains replacing letters with numbers or similar glyphs (e.g., paypa1.com with numeral 1, micros0ft.com with 0, or appending fake subdomains paypal.com.attacker.net).

    6. False-Positive Awareness

    Heuristic scanners look for patterns, not absolute truth. Legitimate promotional campaigns, password expiration notifications, or internal IT notices can trigger urgency or link heuristics. Security teams must corroborate indicators before taking disruptive actions.
